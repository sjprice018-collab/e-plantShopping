# e-plantShopping
Repository name: e-plantShopping

## Project Overview

**e-plantShopping** is a plant shopping web application that allows users to browse a selection of plants and explore plants available for purchase. The application provides a user-friendly interface for viewing plants and navigating a plant shopping experience.

## Features

- Browse a collection of plants.
- View plant products available for purchase.
- Navigate a user-friendly shopping interface.
- Explore plant products through the application.

## Technologies Used

- React
- JavaScript
- HTML
- CSS

## Purpose

This project was developed as part of a web development project to demonstrate front-end development skills, component-based design, and the development of an interactive shopping application.
